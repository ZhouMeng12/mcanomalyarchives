## 玩法特色

### 见闻录 / 异常档案（Codex）
- **见闻录**（`mcanomalyarchives:anomaly_codex`，本模组创造标签内）右键打开档案界面；
- 收录 **UO-001 ~ UO-012** 共 12 个异常条目，按 **项目等级 / 保密协议 / 已知特征** 三个字段展示；
- **解明制**：未在游戏中遇到过时显示 `???`，真正遇到会自动解锁并弹提示
  （每 2 秒扫一次：**附近有该异常实体**或**背包里有对应物品**即算见过；创造/旁观同样记录，
  死亡重生会把手上的档案带过去）；
- 尚未实装的条目会明确标注"档案暂缺"，而不是留空。

### 百变命名牌（UO-008）
一块能**倒置命名因果**的命名牌：不是按特性起名，而是**按名字赋予特性**。
在铁砧上把名字改成某个物品 / 方块 / 生物的名字，被命名的东西就会往那个东西变。

- **物品 → 物品**：改名的物品**真的换成本体**（叫"钻石镐"的木棍就是一把钻石镐），
  但**外观仍是原来的木棍**（客户端渲染层画回源外观），只有性质变；
  耐久取**源物品**的耐久，源物品没有耐久则一律 **100** 点；
- **质料守恒**：能不能改得动取决于"质料"够不够（铁块 ≫ 铁锭 > 木棍……），
  撑不住的名字会让物品**当场炸掉**（正片里木棍→钻石块就是这么炸的）；
- **生物 → 方块**：唯一保留**过程**的一支。生物**立刻失去 AI**、动弹不得，
  身体材质在 **15 秒 ~ 2 分钟**内与目标方块**两张贴图真正交叉溶解**（不是换皮、不是缩放）；
  期间会**夺取周围环境**（吞够 1 个方块量即封顶）；**半路被打死就按进度掉锭和粒**
  （矿物方块按百分比掉，其余按 9 分之 1 折算）；
- **生物 → 物品**：立刻失去 AI 并变成可**右键拿起**的物品，不用等材质；
- **生物 → 生物**：立刻换成目标生物的 **AI / 掉落物 / 固有性质**
  （会被太阳点燃、怕水、药水效果反转等）；
- 变成实体的生物**不会一直活着**——一段时间（当前 60 秒）后**力竭而死**；
- 被命名成"鸡"的动物会开始下蛋，**蛋照原版那样扔出去**（1/8、4 只那套概率），
  孵出来的是**下蛋那只生物的幼体**（"牛蛋"孵出牛犊），而不是小鸡；
- **不可逆**：普通命名牌和第二张百变命名牌都改不回来；只保留正片里的那一支会爆炸；
  对**玩家 / Boss / 本模组异常实体**无效；界面不写解释文字，也不提供指令。

### 幸运粉羊（UO-012）
- 只在平原等温和开阔群系出现；
- **目击满 2 秒**获得幸运；**凝视满 45 秒**它会在你眨眼的一瞬间消失并转移位置；
- **靠得太近或攻击它**会招来**三档灾厄**，最高档没有任何预警；
- 配套成就：幸运粉羊 / 奇迹与你 / 眨眼。

### 虞美人（CornPoppy）
- 注视虞美人会**上瘾**：每 10 秒升一级，等级 10 时冻结无法移动，再盯 10 秒死亡；
- 停止注视转为**悲伤**状态（减速/虚弱/扣血）；
- 虞美人长时间无人注视会触发**花之泣**，128 格内玩家获得高等级悲伤，可通过世界规则取消；
- 注视虞美人可以安抚愤怒状态。

### 云室（CloudDem）
- 云石/云水/云装备/云室传送门一整套云主题内容；
- **伪云**实体在玩家附近高空（y 100~150）周期性出现；
- **云化效果**：二级云化使生物失去 AI、水平飘移并变**灰白贴图**

### 理智系统（Sanity）
- 0~100 持久化理智值，受恐怖事件/伤害扣减，随血量恢复；
- 低理智触发暗角/去饱和/噪点扫描线/幻听等屏幕效果；
- **神经检测仪**：可佩戴头饰，HUD 显示诺德指数/兰达指数/电量（服务端扣电），电量耗尽 HUD 消失。

### 紫怪剧情（PurpleMonster）
- 五阶段剧情演出（对话/变身/抚摸/同化）；
- 低理智（≤15）或低血量（≤30%）且静止 60 秒 → 自然触发；
- 同化完成后 **紫怪** 会随机在**树后/窗外**出现；

### 怪树（StrangeTree / UO-011）
- **钻地**：在怪树附近砍**8 棵完整树**（连通原木簇计棵，一棵树只算 1 棵）触发钻地——清树、翻土、钻地动画 + 地震，3 秒后埋入地下（实体保持存在，可用发光效果观察地底移动）；
- **埋伏-偷袭链**：钻地后锁定砍树玩家，地底追踪（**持续屏幕震颤**）→ 到达后埋伏（小幅震颤）→ 玩家再砍 1 棵 → 从玩家**背后/侧面视野盲区的泥土**钻出（保底 3 格）→ **无视护甲一击必杀**；
- **追杀模式**：可钻出泥土距玩家 >5 格时，树反复夹击（每 1.5 秒一轮），玩家进入 5 格内被秒杀；**种下树苗立即停止追杀**；
- **补种免疫**：砍树后 10 秒内补种树苗 → 计数清零；累计补 3 棵 → 树彻底放弃本次袭击；
- **迁居**：玩家在树旁久留（8 格内 ≥90 秒）、树旁发生爆炸（16 格内）、或 16 格内 5 秒破坏 ≥8 个方块 → 树钻地**换位置**（20~40 格外重新扎根，只换位置不攻击）；
- 树叶被破坏后瞬间再生；树干/实体免疫几乎所有伤害（物理抗性≈基岩）；

### 安布拉（Anbula）
- 狂暴模式、冲锋/跳劈/闪避等自定义 AI，可装备 TACZ 枪械；

### 其他
- 诡异钓竿；
- NPC：斯万/大卫/伊芙琳/波特（送礼、打招呼对话气泡、蹲下右键状态控制）；

## 下载 / 安装

发布版放在 [Releases](https://github.com/ZhouMeng12/mcanomalyarchives/releases) 页，
文件名形如 `strangerecord-<版本>-neoforge-1.21.1.jar`。

1. 装上对应版本的 **NeoForge**（≥ 21.1.190）与 **GeckoLib**（≥ 4，推荐 4.6.6）；TACZ / Curios 可选；
2. 把 jar 放进 `.minecraft/mods`；
3. 启动游戏，模组列表里显示为《MC诡异见闻录》。

自己构建的产物是 `build/libs/modid-1.0.jar` —— **文件名不带版本号**，
实际版本以游戏内模组列表显示的为准。

## 开发 / 构建

```bash
./gradlew build      # 编译打包（产物在 build/libs/）
./gradlew runClient  # 启动开发客户端
```

- 工作区由 **MCreator** 创建。依赖仓库：NeoForge、GeckoLib（见 `settings.gradle`）。
- 模组版本号在 `src/main/resources/META-INF/neoforge.mods.toml`（`build.gradle` 里的 `version` 只决定产物文件名）。
- **MCreator 重新生成代码后请跑一次守卫脚本**，它会校验注册表、语言词条、mixin 注册、
  名称索引等 40 条规则有没有被覆盖掉：
  ```powershell
  pwsh tools/mcreator-guard/guard.ps1 check    # 只检查（apply / snapshot / status 见脚本注释）
  ```
- 手写机制的纯逻辑自检在 `tools/nametag/`（名称解析表、转化时长、掉落换算、产物内容等），
  都是不需要启动游戏就能跑的 Python 脚本。

## 项目结构

```
src/main/java/net/mcreator/mcanomalyarchives/
├── anomaly/     手写的异常机制（nametag 百变命名牌 / pinksheep 幸运粉羊）
├── block/       方块（虞美人/云系列/传送门/怪树树干树叶等）
├── client/      客户端渲染（HUD/气泡/灰白贴图/检测仪/屏幕震颤/命名转化表现）
├── clouding/    云化系统
├── codex/       见闻录（异常档案：条目表/解锁/同步/开场剧情）
├── commands/    命令（/purplegui /sanity 等）
├── compat/      TACZ 兼容
├── config/      模组配置
├── custommodel/ 自定义模型（紫怪触手/紫狗等）
├── dialogue/    对话气泡系统（台词总表 DialogueDatabase.java）
├── effect/      自定义效果处理
├── entity/      实体（安布拉/紫怪/紫狗/NPC/伪云/怪树/粉羊）+ ai 子包
├── entity/ai/   自定义 AI（安布拉近战/远程/主人复仇等）
├── event/       服务端事件（理智/云化/紫怪触发/窥视者/伪云生成）
├── events/      怪树钻地-偷袭-迁居等事件
├── fluid/       自定义流体
├── init/        MCreator 生成的注册表（会被再生成）
├── item/        物品（紫怪触手/诡异钓竿/百变命名牌/见闻录等）
├── mixin/       渲染 Mixin（含"外观不变"与"材质交叉溶解"两个关键注入）
├── network/     自定义网络包（理智同步/震颤/对话气泡/命名转化同步等）
├── potion/      药水效果（上瘾/悲伤/云化）
├── procedures/  MCreator 生成的过程
├── sanity/      理智系统（PlayerSanity 持久化）
└── world/       维度/传送门
```

> 工程上分两区：**MCreator 生成区**（`entity/` `init/` `item/` `client/renderer/` `resources/` `lang/` 等，
> 会被 MCreator 重新生成覆盖）与**手写区**（`anomaly/` `codex/` `dialogue/` `mixin/` `network/` `config/` `tools/`）。
> 手写逻辑一律放在生成区之外，并配 `tools/mcreator-guard/` 守卫脚本（40 条规则）在 MCreator 重新生成后校验完整性。

## 已知事项

- 云化一级（云套装版）目前无视觉表现，二级触发灰白+飘移；
- 紫怪 Boss 战为占位触发器（`PurpleBossFightTrigger`），Boss 本体开发中；
- 伪云/云化实体无自然消失，请配合生成上限使用；
- **UO-002 / UO-006 / UO-007 / UO-009 / UO-010 尚未实装**，见闻录里会显示"档案暂缺"；
- **UO-008 百变命名牌**：
  - 方块转化"内部中空"（变到最后半透明）**没做**，目前只做两张贴图的交叉溶解；
  - `羊吃草`、`末影人传送`、`爬行者自爆` 这类写在各自实体类里、又依赖自身形态的行为**不跟名字走**
    （要跟就得真换本体，属另一套方案）；
  - 掉落的**经验值**仍是原生物的，不随名字变；
  - 项目等级 / 保密协议仍是占位值（wiki 上该条目页面暂缺）。
