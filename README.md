# MC诡异见闻录 (strangerecord)

一个基于 MCreator 开发的 **Minecraft 1.21.1 / NeoForge** 恐怖·诡异题材同人模组。

> 版本：1.1.7.1 ｜ 作者：一只小恐龙 ｜ 内容灵感来源：B站 up 主 SvenTheOrangeBoy ｜ 许可证：GPLv3

## 依赖

| 前置 | 版本 | 必需? |
|------|------|------|
| Minecraft | 1.21.1 | ✅ |
| NeoForge | ≥ 21.1.190 | ✅ |

## 玩法特色

### 虞美人（CornPoppy）
- 注视虞美人会**上瘾**：每 10 秒升一级，等级 10 时冻结无法移动，再盯 10 秒死亡；
- 停止注视转为**悲伤**状态（减速/虚弱/扣血）；
- 虞美人长时间无人注视会触发**花之泣**，128 格内玩家获得高等级悲伤，可通过世界规则取消；
- 注视虞美人可以安抚愤怒状态。

### 云室（CloudDem）
- 云石/云水/云装备/云室传送门一整套云主题内容；
- **伪云**实体在玩家附近高空（y 100~150）周期性出现；
- **云化效果**：二级云化使生物失去 AI、水平飘移并变**灰白贴图**

### 理智系统（Sanity）
- 0~100 持久化理智值，受恐怖事件/伤害扣减，随血量恢复；
- 低理智触发暗角/去饱和/噪点扫描线/幻听等屏幕效果；
- **神经检测仪**：可佩戴头饰，HUD 显示诺德指数/兰达指数/电量（服务端扣电），电量耗尽 HUD 消失。

### 紫怪剧情（PurpleMonster）
- 五阶段剧情演出（对话/变身/抚摸/同化）；
- 低理智（≤15）或低血量（≤30%）且静止 60 秒 → 自然触发；
- 同化完成后 **窥视者** 会随机在**树后/窗外**出现，夜晚低亮度刷新更频繁、距离随遭遇次数逼近（30→20→12 格）；
- 攻击窥视者可触发 Boss 战（触发器已就位，Boss 本体开发中）。

### 安布拉（Anbula）
- 狂暴模式、冲锋/跳劈/闪避等自定义 AI，可装备 TACZ 枪械；

### 其他
- 诡异钓竿；
- NPC：斯万/大卫/伊芙琳/波特（送礼、打招呼对话气泡、蹲下右键状态控制）；

## 安装

1. 安装对应版本 NeoForge + GeckoLib（可选 TACZ/Curios）；
2. 将编译产物 `modid-1.0.jar`（或发布版 jar）放入 `.minecraft/mods`；
3. 启动游戏即可。

## 开发 / 构建

```bash
./gradlew build      # 编译打包（产物在 build/libs/）
./gradlew runClient  # 启动开发客户端
```

- 工作区由 **MCreator** 创建。
- 依赖仓库：NeoForge、GeckoLib（见 `settings.gradle`）。

## 项目结构

```
src/main/java/net/mcreator/strangerecord/
├── block/       方块（虞美人/云系列/传送门等）
├── client/      客户端渲染（HUD/气泡/灰白贴图/检测仪）
├── commands/    命令（/purplegui /sanity 等）
├── compat/      TACZ 兼容
├── dialogue/    对话气泡系统（台词总表 DialogueDatabase.java）
├── entity/      实体（安布拉/紫怪/紫狗/NPC/伪云）
├── event(s)/    服务端事件（理智/云化/紫怪触发/窥视者/伪云生成）
├── init/        MCreator 生成的注册表（会被再生成）
├── mixin/       渲染/动画 Mixin
├── network/     自定义网络包
└── potion/      药水效果（上瘾/悲伤/云化）
```
