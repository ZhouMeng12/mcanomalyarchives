## 一句话设定

一张**深褐色的异常命名牌**：正常命名是"按事物特性给它起名"，它**倒置了这个因果**——**按名字强行赋予特性**。被命名的对象保留原外观，但"内核属性 / 物理属性"被彻底改写，**所有转化都存在明显的代价与损耗**，而且**无法用普通命名牌撤销**。

- 【旁白 4.9-13.9s】"这个**深褐色**的命名牌极其危险，它会通过**扭曲现实**改变一个物体的本质，被它命名的物体将会产生**对应名称的存在属性**。"
- 【旁白 13.9-19.4s】"产生的副作用还会造成**不可挽回的损失**。"
- 【旁白 2:00-2:06】"该命名牌**并不会完全转变物体的形态**，但却能**篡改物体的内核属性**。"
- 【旁白 3:07-3:11】"该命名牌可以**彻底改写物体的物理属性**，且**所有属性转化均存在明显的代价与损耗**。"
- 【弹幕 614.0s 观众总结】"百变命名牌**倒置了命名的因果**：正常是根据事物的特性赋予名字，它是**根据名字赋予特性**。"
- 【简介 原文】"UO-008 是一系列（现存约[x]个）在[数据删除]**矿井宝藏矿车**内发现的异常命名牌，外观呈**深褐色**，区别于普通命名牌。该系列命名牌可对**任意实体、方块或物品**进行命名，被命名对象的核心存在属性将被强制改写为与名称对应的机制与特质，但会**伴随显著的副作用或转换代价**。"

## 核心机制

### 1. 开场事故：矿工的狗 →「土豆」

【旁白 19.4-39.8s】一名矿工给自己的宠物狗命名为**土豆**后：宠物狗**瞬间丧失所有动物活性** → 不久发现**严重脱水死亡** → 遗体呈现明显的"块茎化" → 数日后遗体上**长出了细密的土豆嫩芽**。事件引起热议后被冒险协会收容，正式编号 **UO-008 百变命名牌**。

### 2. 来源与数量

- 【旁白 0:56-1:04】"这些异常命名牌均来自**一处矿井内的矿车宝藏**。全面搜寻后，我们总计收获了 **□** 个异常命名牌。"——数量在正片里被**[数据删除]**。
- 【旁白 1:04-1:07】随后放入"不远处荒地的**收容保险柜**"；派**死刑犯实验人员**展开研究，每人头上戴**神经监视仪**、在信号车内远程监视。
- 【弹幕 58.5s】"来源：和普通命名牌一样，可能经由**废弃矿坑内的宝箱**开出。"

### 3. 使用方式（**关键，直接决定实现**）

- **实体**：直接拿命名牌对生物使用。【旁白 1:26-1:29】派 D196"拿出一张命名牌，让他尝试将一头牛命名成鸡"。
- **物品 / 方块**：**直接命名全部失败**。【旁白 2:11-2:17】"随后我们令 D196 尝试命名一些方块、物品、实体，但所有尝试都以失败告终。"
- 【旁白 2:17-2:26】"直到令 D196 **通过铁砧结合命名牌**将一把**木铲**命名成**下界合金镐**后，竟发现**成功命名**，同时**命名牌被消耗**。"
- → **物品/方块路径必须走铁砧**，名字来自玩家在铁砧输入框里输入的文本。

### 4. 同形态命名（132–197s）

| 实验 | 结果 | 出处 |
|---|---|---|
| 木铲 →「下界合金镐」（铁砧） | 外观没变，获得下界合金镐的**采集能力**；**仅经过五次使用后木铲便损毁** | 【旁白 2:19-2:37】 |
| 原石 →「水」（铁砧，放置后） | 原石**呈现液态化向四周蔓延流动**；液体**黏附性极强**，人员接触后**无法自主挣脱**；液体**不停高速挥发成粉尘**，**11 分钟后彻底消散殆尽** | 【旁白 2:44-3:03】 |
| 木棍 →「钻石块」（铁砧，放置后） | 放置后发生**巨大爆炸**，D196 **当场死亡**；爆炸中心找到**一例极其微小的钻石块颗粒**；推论可**完全转换物质成分**（木棍在极端环境中碳原子重组，等量转换成这一小粒钻石块） | 【旁白 3:16-3:45】 |

### 5. 跨形态命名（197–295s）

**A. 牛 →「鸡」**【旁白 1:26-2:00】
- 命名后**没有任何明显的外形变化**；
- 但该牛**无法再挤出牛奶**；
- 会发出**鸡的怪异叫声**；
- 开始下出**深褐色的"牛蛋"**，且这些牛蛋**可以孵出正常的牛幼仔**；
- 之后该牛开始**不停撞墙**、持续发出**惨烈的悲鸣**；
- **尝试用普通命名牌替换掉该名字 —— 失败**；
- 在多次产蛋后，该牛**在痛苦的挣扎中猝死**。

**B. 羊 →「金块」**【旁白 3:47-4:36】（在离羊 100 米处放置两个等体积金块作为对照）
- 命名后羊**瞬间失去所有生物活性、躯体僵硬**，金块完好无损，一度被认为"物质守恒猜想失败"；
- 然而其后**肉体经过数天仍未腐烂**；部分身体**慢慢被金子取代**；
- 期间**羊的眼里流出了少量泪水**；
- 同时收容所附近**含金元素的设备均出现故障**，修理后发现**有的设备零件已经部分缺失**；
- 最终**整个躯体完全被金子替换**，后期研究显示**其内部结构竟呈现完全中空**；
- 结论：该羊在通过未知途径**不停吸收周围的金元素**；**部分转换遵循物质守恒**。【旁白 4:30-4:36】

**C. 猪 →「钻石镐」**【旁白 4:36-4:54】
- 命名后猪的**意识变得怪异，开始向某处狂奔**，不顾一切寻找附近的石头和矿石并对其进行挖掘；
- 其挖掘的采集能力**等同于一把钻石镐**；
- 然而**挖掘不久后该猪很快就立刻死亡**。

### 7. 实验：地球（392–458s）

【旁白 6:31-7:47】
- 为检测转化能力的极限，让 **D313 将一只兔子命名为「地球」**；
- 安全撤回保障：检测装置会在命名后的 **167 纳秒**自动把 **【负值唱片】**（UO-007）塞入唱片机进行**时空回溯**；
- 命名后，远处监控观测到**声波范围内的时空变得极度扭曲**，发出**刺眼的黄光**；
- 成功回溯，D313、兔子和周围空间**安然无恙**；
- 但后期回收发现，**负值唱片出现了轻微的损耗**。
- 因该系列命名牌**数量有限**，所有相关实验线**暂时终止**，命名牌**完成装车**、即将送往协会的高层设施。

## 可做进模组的点（差异化设计）

1. **核心机制＝"名字即代码"的反向命名**：玩家自己在铁砧里输入的名字决定效果，目标**保留原模型与贴图**、只换内核。这是本模组第一个**玩家可自由输入**的异常，与粉羊（被动触发）、虞美人（注视）、怪树（砍树计数）完全不同维度。
2. **使用方式直接照抄正片**：实体走右键；**物品/方块必须在铁砧里与命名牌结合**（`AnvilUpdateEvent`）——既还原，又天然把"起名字"这个动作变成玩家的仪式感。
3. **代价可指数化**：物品**耐久上限 = 名字字符数**（"下界合金镐"5 字 → 5 次后用碎）；生物按新身份行动次数计寿；流体类有存活时间（水 = 11 分钟，正好是本期时长）；跨类转化以**爆炸**支付。
4. **不可逆是压力来源**：正片明确"用普通命名牌改回去**失败**"——做成硬规则，玩家每次动手前必须想清楚。
5. **材料掠夺**（最像"异常"的一条）：高价值材料名作用于生物时，转化随时间推进，并**从附近环境掠夺对应元素**（金 → 抽走基地里的金设备，零件缺失）。玩家的贪婪会亲手拆掉自己的基地。
6. **未命中即无效**：只认主流叫法（【弹幕 240.6s】"地蛋"这种别称不生效），天然解释了"为什么不是万能许愿机"，也让词条可持续扩充。
7. **来源**：接进 vanilla `chests/abandoned_mineshaft`（矿井矿车宝藏）战利品，用全局战利品修饰器实现。
8. **与既有内容的连接**：乱码名字产物 = 与 **UO-002 不存在的村庄**同源的乱码物品；极限命名（地球）需要 **UO-007 负值唱片**兜底；命名牌的暗线（人变成牌）以后可与收容失效剧情串起来。

### 2. 「实验6 实体→物」猪 →「钻石镐」：**外形从头到尾没变过**

- **全程 20 多个采样时刻（含 1 fps 加密帧）里，猪始终是一只标准原版粉猪**：粉色方块身体、四条腿、
  猪鼻鼻孔、黑眼睛、耳朵。**没有任何一帧出现镐子形状，也没有变成掉落物。**
- **278–279s 有一张图解**：左边一只粉猪标「**猪**」，中间白箭头，右边**几何形状完全相同**的另一只粉猪
  标「**钻石镐**」——放大 3–6 倍反复核对，右边那只轮廓就是猪，没有镐头没有木柄。
- 变化只有**姿势与位置**：站着 → 平台转身 → 狂奔出监控画面 → 出现在矿坑里 → 低头贴住方块"啃咬"
  → **292s 整只旋转约 90° 侧躺** → 293/294s 侧躺不动。
- 290–291s 字幕是关键：**「它啃咬的采集能力 等同于一把钻石镐」**；293–294s：**「该猪很快就力竭死亡,」**。
- **全片没有一帧"生物变成地上一件可捡的物品"**；猪停止活动时地上仍是一只可见的粉猪侧躺着。

### 3. 视频自己的分类标注（作者后期叠加）

「**实验5 实体→块**」（230s）→「**实验6 实体→物**」（275–277s）→「**实验7 实体→人**」（300s），
编号递增。视频作者本人把这三类分开处理，与模组里的三种终局完全对得上。

### 4. 这几条画面证据对设计的含义

- **视频表现"变成"几乎全靠旁白，画面本身不做模型替换**。它的核心规则是"**外观不变、只换性质**"
  （图解里"钻石镐"那一格画的还是猪，最能说明这一点）。
- 因此模组里"生物→物品 = 瞬间变成可拿起的物品"是**作者自己定的规则，视频里没有这一幕**；
