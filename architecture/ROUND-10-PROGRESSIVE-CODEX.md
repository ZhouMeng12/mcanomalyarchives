# 分段遭遇与逐条见闻（已实现）

## 见闻录

- 首次看见异常或持有对应物品，只建立初见条目。正文不再一次性展示旧的全部性质文案。
- `CodexObservations` 定义 31 类性质。真实事件调用 `record`；同一玩家只记一次，按经历顺序追加。
- 每条性质独立起页，目录右侧显示已记录的性质数。文字、书页和点击区域使用同一缩放坐标。
- 持久数据保存在玩家 `McanomalyCodexObservations` 字符串中，使用稳定 ID；重生时复制，打开书及新增记录时由服务器同步。
- 旧存档的条目解锁状态保留。未曾单独记录的性质需要重新遭遇，不由旧的条目位掩码推断。
- 目击扫描合并为一次实体查询，仅处理本模组活体，要求可见、无遮挡、在玩家前方及 48 格内。物品初见通过背包识别；虞美人也可通过实际视线命中的方块识别。

记录来源：

| 异常 | 已接入的性质 |
| --- | --- |
| 伪云 | 小型个体、黑色个体、实际接触受伤、液体转化、红色个体、黑云消除方块 |
| 乱码 | 同一物品界面中的感染实际发生 |
| 虞美人 | 凝视导致上瘾、离开后出现悲伤反应 |
| 跨维钓竿 | 异常收线、远距异常、实际钓获活体 |
| 紫怪 | 自然现身、改变形态、同化、窥视、获得触手、完成动物接触 |
| 命名牌 | 改写对象、乱码、工具行为、抹除、模仿玩家、实际吸收材料、不稳定产物爆炸 |
| 怪树 | 钻地/钻出/夹击、补种使追踪中止、根部暴露触发钻地 |
| 粉羊 | 祝福、灾厄、眨眼消失 |

有明确执行点的性质从对应逻辑直接记录；无指定受影响玩家的事件，通过 `witness` 只记给范围内正在看向事件的玩家。扫描不凭空解锁未发生的事件。

## 紫怪出现

- 自然现身前 4 秒、2 秒和 0.5 秒提供低音与局部紫色尘粒预兆；现身和离开使用一致的粒子表现。
- 自然演员寻找附近有碰撞空间和支撑面的站位；找不到站位时保留已满足的等待时间，每秒重试。
- 静止判定补充实际位置变化与水平运动，避免只读输入字段而误判。
- 窥视者生成点优先玩家余光与侧后方，允许在玩家附近高度寻找树冠下或洞内的可站立位置。
- 被看见的判定要求视线无遮挡，包含首次约 30 格出现的距离。看见后仍停留原有 4 秒，期间出现分段消散预兆。
- 修正普通渲染分支忽略紫色贴图变体的问题。全服共享与关联玩家清理规则继续使用既有会话模块。
