# 幸运粉羊：情境事件与观察规则

普通目击采用有利事件；接近和攻击改为按现场条件挑选灾厄链。视频是观察者效应和距离演示的参考，以下时长、收益和事件属于游戏化设计。

## 触发流程

连续直接观察 2 秒，绑定本次出现的第一位确认目击者。15～45 秒后，在该玩家附近已加载的区域选择合适事件，先播放环境声或动作，约 3 秒后复查现场，再结算。成功后给予 60 秒幸运效果并记录目击进度。

同一玩家实例两分钟内只安排一条事件；优先排除最近三条成功事件，没有其他合适事件时允许重复。粉羊转移开启新的目击轮次，不取消已经归属于上一位目击者的事件。重生、退出、换维度、关闭规则或离开事件区域会阻止延迟收益。没有合适环境时不强行制造奖励。

| 事件 | 前提 | 前兆与结果 |
|---|---|---|
| 草穗落籽 | 附近有短草 | 草叶沙沙响，短草消失并留下 3 粒小麦种子 |
| 恰逢成熟 | 有未成熟作物 | 作物附近出现少量生长粒子，随后成熟，可正常收获 |
| 莓果丰收 | 有未成熟浆果丛 | 灌木响动，浆果进入可采摘的成熟状态 |
| 蜂群满载 | 有未满蜂巢，附近存在蜜蜂 | 授粉声后蜂蜜达到可采集状态；不自动取蜜，正常蜜蜂规则仍适用 |
| 熟果坠落 | 非持久橡树或深色橡树叶，下方为空气 | 树叶沙沙响，掉下 2 个苹果 |
| 雨后拔节 | 竹子顶端有空间 | 竹节响动，向上长出一节 |
| 蔗田抽高 | 有符合高度条件的甘蔗顶端 | 叶片响动，向上长出一节 |
| 母鸡报喜 | 附近有成年鸡 | 鸡叫后下一个蛋，保留实际掉落物 |
| 吃草长毛 | 成年剪毛羊站在草方块上 | 播放吃草动作，草变泥土，羊毛恢复 |
| 猫叼礼物 | 自己驯服且未命令坐下的猫 | 猫叫并尝试走近，留下 2 张兔子皮 |
| 铁卫解围 | 有空闲铁傀儡和正在攻击玩家的普通怪物 | 铁傀儡脚步响起，随后介入战斗；排除苦力怕、凋灵、监守者 |
| 顺流失物 | 附近水里已有掉落物 | 水花出现，原掉落物得到朝玩家方向的推动；不复制物品、不穿墙传送 |
| 海豚护航 | 玩家在水中，附近有海豚 | 海豚鸣叫，靠近玩家，给予 30 秒海豚的恩惠 |
| 旅鸡来访 | 其他事件均不适用，附近视野外有安全草地 | 一只普通鸡出现并尝试走近，随后下蛋；不能找到安全位置则放弃 |

种植类事件仅修改符合条件的目标方块；不挖洞、不引爆 TNT、不替换容器。中途收割、剪毛状态改变、目标动物离开或死亡，都会使对应事件失效。解围和水流事件通过实际 AI 和运动执行，不保证怪物必败或掉落物必定到达背包。

## 观察、转移与灾厄

- 全部玩家观察状态先结算，再决定羊是否消失。某个人眨眼不会覆盖其他人的观察。
- 独立眨眼约每 45～55 秒一次，闭眼窗口 5 tick；只有在该次眨眼期间真的无人观察并触发转移，才授予眨眼进度。
- 连续观察 3 分钟后，每秒有 1/120 概率出现共同眼酸事件。提前两秒提示，然后当前观察者同时闭眼。
- 羊离开和出现时不再播放幽匿传送特效。目的地要求已加载、可站立，并避开玩家正看着的位置。
- 距离档位为 10／8／3 格；灾厄之间至少间隔 10 秒，冷却期间的距离档位不消耗。关闭规则后，近战和投射物也不再触发新灾厄。
- 当前只接入玩家直接视线；未接入监控摄像机或其他模组的远程观察。

## 验证范围

自动测试覆盖多人观察处理顺序、单人/共同闭眼、第一目击者不能被抢占、转移后重新绑定、连续注视中断、事件冷却和历史去重、取消代次。世界方块、动物寻路、声音及粒子已编译验证，仍需进入 Minecraft 验证观感与实际交互。

## 灾厄事件链（当前自动事件池）

| 事件 | 现场要求 | 流程与解除方式 |
|---|---|---|
| 洞口拦路 | 9～20 格外存在可站立空间、石质顶壁，出生时无人直视 | 先听到僵尸声，约 1 秒后出现持铁剑的僵尸，约 3 秒后行动；释放前杀死源实体可中断 |
| 追鸡撞祸 | 第二档起，需要远处可站立位置，出生时无人直视 | 鸡叫 → 小僵尸与鸡出现 → 骑士开始行动；准备期杀死鸡或骑士会取消剩余准备 |
| 顶壁落石 | 玩家上方 4～14 格有石材、沙或沙砾，下面为空气，且 mobGriefing 开启 | 碎屑与声音 → 约 3 秒后原位置的方块真实掉落 → 按落距结算伤害，最多 40 点；移走该方块或填住下方空隙会中断 |
| 误射穿空 | 最高档，需要射手位、4 格外爆破点，以及两段畅通路径 | 骷髅、可见 TNT 与慢速箭出现 → 同一支箭到达爆破点 → 实际小爆炸加速它 → 箭按初始瞄准方向飞出，之后受重力和碰撞影响 |
| 陨石擦天 | 最高档、露天、天空有空间，轨迹与爆炸邻域均已加载 | 三颗错峰出现，沿固定路线加速下落；实际碰撞位置引爆，使用正常爆炸伤害、遮挡和减伤规则 |

误射链是游戏化的临时事件布景，不会生成或寻找一整个矿场。TNT 的小爆炸有真实伤害与冲击，但不破坏地形；加速是该次爆破对事件箭的受控效果。准备中的箭撞到其他目标，或射手/TNT/箭被移除，都会取消后续加速。箭发射后不跟踪玩家。落石是真实方块迁移，不额外复制方块。

普通事件链在准备期验证目标仍为原玩家、仍在原维度、仍存活、规则仍开启、相关区块已加载；换维度再回来也不能恢复旧事件。准备事件最迟 8 秒超时清理。已经释放的普通怪物、箭、落石继续按游戏物理存在；已经在天上的陨石继续固定飞行，尚未出现的陨石会在目标失效后取消。停止服务器时清理未完成的事件与临时源实体。

灾厄成功启动才消耗距离档位，至少相隔 10 秒。找不到场景时每 2 秒重试，不用不匹配的灾难填补。旧铁砧雨、TNT 地毯、龙息齐射、水晶环不再进入自动选择；遗留水晶引爆队列也取消了“水晶被移除后补炸”。陨石移除了 30 格内补 200 点伤害和手动清空受击无敌时间的逻辑。

新增回归覆盖：来源创建与释放只执行一次、来源恰在释放 tick 被移除、箭未到达爆破点不会提前释放、超时取消、目标失效不可恢复，以及固定陨石轨迹的加速、积分终点和时间边界。现场寻路、箭/TNT 交互和多人观感仍需游戏内实测。
