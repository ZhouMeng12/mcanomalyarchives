# 百变命名牌视频效果实现审计

日期：2026-10-25。对照工程内《百变命名牌》参考卡、完整旁白和抽帧记录（`docs/video-research/uo-008-name-tag.md`），检查服务端代码、渲染接线与最新模型预览。本记录描述的是代码现状；静态检查不等于游戏内复现。

## 结果

| 视频命名案例 | 目前项目实际行为 | 判断 |
| --- | --- | --- |
| 狗→土豆 | 命名时立即删除生物，掉 1–3 个普通土豆；在草方块、泥土或耕地上直接长出成熟马铃薯植株。没有先失去活性、脱水死亡、遗体块茎化、几天后发芽的过程。 | 部分实现；过程和数量都不同 |
| 木铲→下界合金镐 | 铁砧输出真正的下界合金镐物品，外观和能力都换成镐；耐久设为源木铲的最大耐久。 | 没有保留木铲外形；视频的 5 次使用也没按现状实现。源木铲通常可用 59 点，代码不设 5 |
| 原石→水 | `MaterialUnits.itemFormOf` 对水这类无物品形态的方块返回空，铁砧流程会拒绝输出。没有扩散、黏附、约 11 分钟消散。 | 未实现 |
| 木棍→钻石块 | 质料不足会生成不稳定产物，右键使用时单次爆炸，威力依质料差值并封顶 6，按 TNT 规则破坏地形，留下少量目标残渣。 | 核心惩罚已做；当前是右键即爆，没有视频中的压缩视觉，触发时机与“放下后爆炸”仍需在客户端验证 |
| 牛→鸡 | 不能挤奶、按间隔下蛋、记录原物种并让蛋孵出牛，均有实现。目标 AI 也被替换。不过 `NamedEntityAppearance` 会把牛画成鸡，和视频保留牛形相反；原实体其余牛叫声、撞墙和持续悲鸣没有成套实现；最多约 60 秒就力竭死亡，不按下蛋次数结算。 | 多项规则有做；外观与事件演出不忠于视频 |
| 羊→金块 | 静止、计时、周围金材料扫描、吸收进度与中间斑块有实现。当前 `NamedMorphClient` 将金块贴图覆盖整副身体；服务端结束会删除羊并尝试放置一个完整金块。视频画面是脸与小腿逐步显金，羊毛身体一直留白，末段整体透明。眼泪没有实现。 | 资源和转化时钟已做；最显眼的材质/终态与视频不同。当前扫描超量边界也需修复 |
| 猪→钻石镐 | “钻石镐”解析成物品，物品分支调用 `convertToMaterial`，把猪立即替换为钻石镐掉落物。不会保留猪模型、寻找石矿或挖掘，也不会以挖到力竭的方式死亡。 | 未实现视频中的实体→工具行为 |
| D363→已故 D196 的名字 | 该名字不对应生物注册名，也不是特殊规则，查不到目标后静默不处理；没有动作模仿或精神崩溃事件。 | 未实现 |
| D473→D23 的 56 字母姓名 | 目前姓名只按注册表名称解析；没有配对记忆体、同步动作、流泪或崩溃规则。 | 未实现 |
| 木棍→乱码字符 | 特殊规则可以识别部分标点组合，但分支为空操作，没有生成 UO-002 同源乱码物品。 | 只有分类识别，效果未实现 |
| D187→无 | 对可命名的非玩家生物会立即 `discard`，没有记忆、监控和历史的认知擦除。玩家被命名流程拒绝。 | 只有实体消失的一部分 |
| 兔子→地球 | `EARTH` 分支为空操作；没有黄光、时空扭曲或负值唱片回溯。 | 未实现 |

## 最要紧的实现错位

视频的共同原则是保留原物轮廓，改写性质。当前游戏代码有相反的表现：命名为其他生物时客户端绘制目标生物替身；命名为工具时稳定产物直接换成真正的工具；羊转金块最后删掉实体。此前对预览的材质修订只改变交互预览，没有改变游戏渲染代码。要让视频例子真正对齐，实体视觉层、物品视觉层和羊终态都还要接回原体轮廓，同时保持独立的目标行为。

第二个错位是“文本/叙述标注不等于已实现行为”。本项目现在有大量材料单位、目标战利品、特殊名称解析和注释，但是否实现应按对应的服务端事件、实体 AI、声音/状态和结局分别判定。上表按具体代码路径核对，未把只有注释或分类器的例子算作完成功能。

## 本轮材质修正

- 不明残肢的皮肉表面改成近黑色，保留极少量冷灰裂口与浅色断面骨质。
- 荧光鱿鱼参考原版体型，只保留方形躯干与八条触腕；独立眼点、胸口核心和腿尖装饰都从模型和材质中删除。
- 蒲公英牛的花朵几何改为两张交叉的原版 dandelion 平面贴图；不再使用金色立方花冠。
- 黄金羊采用羊头/四肢先出现低饱和金属斑、白色羊毛身体保持原色、后段整体渐隐的预览表现；移除像整颗金块的漂浮材料方块。

这三项只更新本地演示资产；对应游戏内模型、纹理与动画仍未修改。
