# UO-007 负值物品：原版负数显示

更新：2026-11-14。

## 数量

负苹果在物品格右下角显示原版白字、阴影和位置：一个是 -1，堆叠为 -2、-3，拆分与合并随原版数量变化；用完归零后消失。NegativeItemCountMixin 只替换原版 renderItemDecorations 的数量标签，走原版绘制，不再叠加红字或额外数量说明。

1.21.1 的负数 ItemStack.count 会被判为空栈，存储和同步也不接受负计数，因此底层保留正数数量，显示为其相反数；不全局修改原版栈、合并与网络规则。

## 耐久

保留原有 CUSTOM_DATA.UO007NegativeDurability 计数与旧物品兼容。初始 -1561，每次采掘/攻击加 1，到 0 消失。getDamage 为原版提供 maxDamage - signedRemaining；因此 F3+H 原生耐久提示显示负值，例如 -1561 / 1561，且使用原版红色耐久条。

用户明确选择原版负耐久条向左越出格子的表现，故不再限制 getBarWidth 为正，也不再覆写 getBarColor。原“负耐久”额外红色说明删除。无需更改已有物品 ID 或重建旧物品。

## 苹果修复

先记录进食前的饱食/饱和度，再反向减去普通苹果的 4 点饱食与 2.4 点饱和，均不低于零，饱和度不超过饱食度。修复满饱食时先被原版封顶、随后扣八点导致实际惩罚加倍的问题，按用户此前确认的苹果恢复量反向执行。

## 验证

负数量标签、-1561 到 0 的每次推进、原版负剩余耐久映射、溢出保护、满饱食扣减边界；检查 Mixin 选择器匹配真实 NeoForge GuiGraphics 方法，以及工具继承原版耐久条与提示路径。没有进入 Minecraft 实测界面。

## 负弓与负箭（2026-11-14）

来源：BV1A55Q6dEJJ，实验 5「负弓」。按用户最新修正，负弓不要求预装弹药，每次有效松弦补回一支普通 minecraft:arrow；背包满时掉落在脚边，创造模式不发箭。右键沿用原版拉弓动作、视角与三阶段 pulling/pull 模型。负弓耐久从 -384 向零推进一次，归零损毁；创造模式保留原版不消耗习惯。

松弦后不产生出射箭，延迟 100 tick 后从原瞄准方向生成高速返射箭。32 格、5 秒、速度 4 格/tick 是本实现的游戏参数，并非视频明示数值。生成点取原射线路径上首个碰撞面之前；发射时瞄准原射手当前躯干，此后沿直线飞行，不持续追踪。物理遮挡可以挡住箭，射手可以移动躲开；命中伤害为 1000，仍通过原版伤害系统处理盾牌、创造免疫和不死图腾。

回箭只检测原射手，避免误伤无关玩家。服务器玩家任务检查实体身份和存活状态，换维度时推进独立 epoch，生成前与飞行中都检查该值，因此换维度后立刻返回也不会恢复旧箭。退出/重生取消玩家任务，飞行箭在原射手失效或飞行 80 tick 后消失，不保存到存档，不强制加载远处区块。松弦 20 tick 冷却限制排队数量。

服务器只在有效松弦且成功安排返射后补箭，并推进负耐久。旧 negative_arrow 注册 ID 保留以兼容已保存物品，但从创造栏移除，不参与负弓装填；普通箭保持原版正数量显示。创造栏与见闻录物品发现已接入：松弦未出箭却补箭、目击/遭遇回箭分别记录，获得物品时不会提前解锁返射性质。

材质由 tools/assets/build-negative-bow-assets.ps1 从本机 Minecraft 1.21.1 客户端 jar 提取，逐像素执行 RGB = 255 - RGB，保留 alpha、尺寸及原版模型持握变换。包含弓、三阶段拉弓、箭物品及箭实体贴图。negative_music_disc.png 同样从绿色中心的 music_disc_cat 反色；唱片随后已注册并接入局部回溯，详见 NEGATIVE-DISC-IMPLEMENTATION.md。

MCreator：弓箭物品和实体使用独立注册表，实体注册入口放在主类已有 mod init 用户代码区。客户端模型属性和渲染器使用仅客户端的自动订阅类，保护清单增加实体入口和资源存在性检查。

已验证：Java 编译、原有负值物品测试、材质 RGB/alpha/尺寸逐像素对照、模型引用与中英文名称、打包资源和 MCreator 守卫检查。尚未进入游戏验证拉弓动画、返射碰撞和多人场景。


## 负值方块与普通返射箭（2026-11-14 后续）

用户本轮选择只补方块，护甲暂缓。已注册负泥土、负橡木原木、负橡木木板，原版纹理 RGB 反色且保留 alpha；使用原版方块物品模型，支持原版白字负数量、堆叠、拆分和放置权限。三种物品共享放置结果但保留独立物品名称；一个负原木可无序合成为四个负木板。

依据负值物品视频实验 2/3 的黑色空间，放置后产生无碰撞的黑色立方体，接触活体造成致命 genericKill 伤害；创造/旁观豁免。走原版死亡和重生流程，不直接移除玩家或伪造死亡界面。黑块不产生掉落，不可常规挖掘，分六阶段消散，每阶段 100 tick，合计 600 tick（正常 20 TPS 下 30 秒）。用保存于方块状态的 age 和原版排程 tick 继续生命周期，区块未加载时不强制加载。像素透明缺口渐增；仅表现黑色空间，没有修改原版光照数值为负数。

返射仍保留仅命中原射手、延迟五秒和致命效果，用原版 arrow 实体贴图与“箭”名称；自定义实体类负责定向伤害，旧负值箭物品只为兼容旧存档保留，不作为弹药或新掉落物。

验证：Java 编译，负值数量/耐久及时间窗口测试，黑块 600 tick 生命周期及恢复中间阶段测试，MCreator 守卫检查、打包资源验证。尚未进行游戏内放置、触碰、多人补箭和重生测试。
