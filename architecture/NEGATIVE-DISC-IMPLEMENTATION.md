# 负值唱片：局部时间倒流

2026-11-14。用户确认：每次成功回溯消耗一次，共十次；负值 cat 唱片材质为原版绿芯唱片逐像素反色。

## 游戏流程

原版唱片机附近有玩家时自动开始记录。插入 `mcanomalyarchives:negative_music_disc`，回溯同维度球形半径 50 格内最多约十秒的历史。每五 tick 采样一次，不足十秒使用已有连续记录，至少需要两帧。

演出共 60 tick：低频冲击和扩张波纹、短暂反色与静止，随后轨迹倒放、灰紫暗角、径向重影和收缩波纹，最后恢复正常色彩。使用 cat 原曲片段倒放混合合成低频，镜头震动沿用舒适度配置，不强制转向。渲染使用独立目标并只回写颜色，不复制深度缓冲。

客户端先演出，服务器在结束时统一恢复真实状态。记录方块改变、原版方块实体内容、排程中的方块/流体 tick、生物与掉落物 NBT、玩家位置/背包/末影箱/血量/状态效果/饥饿/经验及骑乘关系。玩家视角、成就与见闻录不倒退。恢复时抑制邻接连锁反应和容器自动掉落；恢复失败尝试恢复开始前快照。

成功才把唱片 UUID 的损耗写入独立的 SavedData；历史快照不能撤销损耗。十次耗尽后清除对应唱片。新唱片显示原版负耐久表现，F3+H 为 -10 / 10，逐次向零推进。

## 当前边界

- 不加载远处区块，区域需已经加载；同维度同时只进行一次倒流。每维度最多记录四台附近唱片机。
- 非原版方块实体、临时合成菜单或未清空的 2×2 合成格会打断记录。恢复完整十秒记录后才能使用。箱子、漏斗、发射器、熔炉、潜影盒、酿造台的界面允许记录。
- 跨界不再否决回溯；离线或已换维度的玩家跳过，仍恢复本区域其他对象。详见文末本轮规则。
- 限制快照中的实体/方块实体数、NBT 字节数和方块改变数量，超额取消记录；不是整个世界的无限历史。
- 不记录天气、全局时间、全服任务/计分板等区域外状态。任意模组实体的独立全局管理器不一定随 NBT 恢复。
- 播放时退出或换维度取消，停服前取消演出并恢复排程；历史不跨服务器重启保存，唱片损耗保存。

## 维护和验证

实现分离在 anomaly/rewind、client/rewind 与 Rewind*Mixin 中；物品是独立 UO007 注册表。中英文名称、提示和分段见闻同时写入 MCreator language_map、资源语言、守卫 canonical。用 tools/lang/sync_negative_bow.py 同步这些负值物品键。

自动测试覆盖十秒窗口、新鲜度、中断、非采样时刻插入、损耗上限/保存、九个 Mixin 的真实方法及 shadow 字段。编译与资源检查不能替代游戏实测。

待游戏验证：单人和双人插盘、箱子取放后倒流、死亡与图腾、骑乘、熔炉与液体、播放时退出、使用第十次后唱片消失、资源重载和窗口尺寸变化。先在测试世界验证这些路径，再用于重要世界。

## 触发与外部特效修正

MCreator 打开工作区后仍可能用内存中的旧 language_map 覆盖资源；现在 repairMcreatorGeneratedSources 在 processResources 之前从守卫 canonical 补回手写语言键，不依赖 Python 或关闭编辑器。已通过实际删除 warming 提示后重新构建验证自动恢复。

显式插盘的唱片机优先获得最多四个记录槽之一，避免第五台永远不记录；额外插盘采样按时间保留，避免频繁插入挤掉完整十秒历史。球体之外的包围盒角落区块不再作为加载前提。不支持容器的保护仍保留；跨界保护已按文末规则移除。

旁观者可见的唱片效果增加三条半径 50 格的大圆边界；负弓返箭出生位置增加紫色圆环，沿飞行段发送服务器粒子拖尾。没有改变伤害、弹道或延迟。编译和十二项负值/回溯测试通过；新增外部特效尚未进入游戏目视验证。


## 移除跨界否决（用户确认）

不再调用或保留 validateBoundary；玩家/生物/掉落物跨越球形边界、库存变化、边缘容器变化、边缘方块变化和原先 64/96 格限制均不再否决回溯。仍按历史快照恢复，唱片最多成功使用十次。没有追加物品流转追踪或去重，因此跨界搬运可能保留区域外物品并恢复历史副本，这是本轮明确移除防复制检查后的行为。

玩家离线或已换维度时跳过该玩家，其他对象继续恢复；已在其他维度加载的实体跳过，避免跨维度产生同 UUID 实体。没有新增强制加载远处区块或跨维度传送。记录为空、区域未加载、数据容量、未支持的方块实体和临时合成栏检查仍用于保证当前恢复流程能执行。
