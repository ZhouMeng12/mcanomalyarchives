# 0003：怪树的完整状态由实体恢复记录持有

日期：2026-10-06。状态：已实施；首次验证见 `../ROUND-3.md`，
后来 PR 自检的补强见 `../PR-FIXES.md`。别只看首次的成功路径就宣布验收完成。

## 问题

旧的 Burrow/Ambush/Relocate 三个处理器，各自维护伐木计数、已清掉的树身、原基座、目标、
追杀和迁居回调。写进实体存档的只有姿态。一旦卸载或停服，快照和回调都丢了，
重载后可能留下地下或攻击姿态；迁居找不到位置时，只恢复了姿态，树身就永远消失了。

## 模块

- `StrangeTreeState`：生产用的阶段转换、目标、一次性击杀和恢复快照，不引用任何 Minecraft 对象。
- `StrangeTreeProgress`：玩家在某个维度里的伐木和补种会话。
- `StrangeTreeNbt`：实际在用的、带版本的 NBT 编码器，测试里不再另抄一套格式。
- `StrangeTreeWorld`：已加载世界的查询、几何、树身捕获与还原，以及效果 adapter。
- `StrangeTreeModule`：唯一的事件接入点，管生命周期，并把状态映射成世界里的效果。

旧的三个处理器已删除，主类不再初始化它们；`StrangeTreeHandler` 还负责结构补实体。
旧源码保留在初始 Git 提交 `0cd5406` 里。资源注册名和客户端姿态 0～4 都没变。

## 保存与事务顺序

当前是版本 2（仍可读取没有撤回计划的版本 1），存在实体的 `NeoForgeData.McanomalyarchivesTreeRuntime` 里。
NeoForge 21.1.190 的 `Entity.saveWithoutId` 会在 `addAdditionalSaveData` 之前复制 `persistentData`，
所以完整快照不能放到生成区的保存钩子里临时拼装。

1. 捕获原树干和树叶、坐标、方块状态，以及实际的脚底原基座。
2. 把操作阶段和完整快照写进实体的 `persistentData`。
3. 这之后才清树、翻土、切换视觉状态。
4. 世界恢复成功后，才清掉 journal、恢复站立。

PR 自检之后补强了几点：

- 整棵树的高度、边界和已加载区块先预检；每次写入必须返回 true，且读回的状态要匹配。
- 迁居的每次写入之前，先保存目的地的平移和尝试索引 `PlacementUndo`，被拒绝的那次写入也算在内。
- 出错或重载时，必须先清掉目的地上预期的树块，再还原原树；撤回失败或区块未加载时，计划会保留。
- 玩家后来放的其他方块、以及没尝试过的位置，都不会被撤回；已经撤回成空气的位置也不会重复删除。
- `finishStanding` 不接受仍带着 PlacementUndo 的状态，避免误删快照，或出现两棵树。
- 这不是跨实体文件和区块文件的磁盘 ACID 事务。异常关机导致两类文件保存不同步的情况，
  还需要更广泛的崩溃测试。

阶段或目标变化时才重写记录；平时每 tick 只更新进度，不会反复构造最多 567 个方块记录。
弱缓存以实体实例为键，值里不存实体、世界或玩家的引用。计时只在实体真正 tick 时推进，
不会按离线的时间去执行攻击。

## 重载策略

- 加载到活跃记录时：取消目标和没完成的攻击，进入 RECOVERING，恢复原基座和树身。
- 等到第一个安全的实体 tick，才去查询或修改世界，避免 EntityJoinLevelEvent 在区块还没到 FULL 时死锁。
- 原基座或 journal 所在的区块没加载时，不强制加载；记录保留，每 20 tick 重试一次。
- 只往空气位置填回。玩家后来放的方块优先，不会被覆盖；恢复成功后，丢弃这次操作的快照。
- 未知版本、损坏的记录，或活跃记录的维度不符：保留原记录，隔离行为并警告，不会跨维度写地形。
- “损坏”包括非法 SNBT、不是本模组的树块、未知的实际属性，或无效的属性值，
  这些都在归一化和写回之前就校验掉。
- 旧版本的活跃实体没有 journal：恢复到安全姿态，不假造已经丢失的方块；
  如果潜地后原基座已经丢了，只能用当前这一列的地面。
- 停服期间不会强行还原未加载的世界；已保存的记录留到下次加载时恢复。

这一轮选的是安全地恢复站立，而不是离线后接着袭击。要续追的话，得另外改这个策略，并补生命周期测试。

## 保留与修正

- 代码里的这些参数都保留：8 棵、10 秒/3 格补种、60 tick 钻地、30 tick 钻出、21 tick 击杀、
  40 tick 夹击、90 秒潜伏、3.1/1.5/0.4/0 的穿透速度，以及 20～40 格的迁居距离。
- 现有的绑定规则不变：钻地之后第一次砍树绑定目标，不会偷偷改成第八棵的伐木者。
- 迁居按实际代码保留：4 格内久留 45 秒，或 5 秒内破坏 10 个方块；最小钻出距离是 4 格。
  旧注释和 README 里的 8/90/8/3 已经同步改掉。
- 迁居的平移改用实体脚底锚点；地面查询能认出本模组的树块，修掉了树冠被当成地面的问题。
- 迁居失败会还原完整树身，不再只是切回姿态。
- 补种取消覆盖整条追杀链，包括最后出手前的等待，防止旧的追杀表提前删了目标又去击杀。
  普通的近身夹击没有新增种树中断规则。
- 目标退出、死亡、Clone 或换维度时，会取消没完成的攻击；已经消费掉的击杀目标，
  不能再去击杀重生后、UUID 相同的玩家。
- 普通计时保留原来的时长常量，改成按状态转换计时；旧的嵌套排队多出来的那一 tick 偏移不再保留。
